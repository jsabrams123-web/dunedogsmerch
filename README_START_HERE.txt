How to run on Mac:
1. Open this folder in VS Code.
2. Open Terminal in VS Code.
3. Run:
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   python3 manage.py runserver
4. Open:
   http://127.0.0.1:8000/
5. Admin panel:
   http://127.0.0.1:8000/admin/
